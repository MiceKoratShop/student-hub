ไม่พบข้อมูลนักศึกษา

ยังไม่มีข้อมูลนักศึกษาในระบบ หรือไม่ตรงกับเงื่อนไขการค้นหาที่คุณระบุ

ตั้งค่า Google Apps Script API (สำหรับ Netlify)

เมื่อนำเว็บแอปนี้ไปติดตั้งบน Netlify (app.netlify.com) ให้วาง Web App URL ของ Google Apps Script ที่ Deploy ไว้ เพื่อเชื่อมต่อ Google Sheets & Google Drive แบบสด Real-time

*URL จะต้องลงท้ายด้วย /exec
วิธีรับ Web App URL จาก Google Apps Script:
  1. เปิดไฟล์ Code.gs ในโปรเจกต์ Google Apps Script
  2. กดปุ่ม Deploy (การทำให้ใช้งานได้) > New deployment (การทำให้ใช้งานได้ใหม่)
  3. เลือกประเภท Web app (เว็บแอป)
  4. ตั้งค่า Execute as: Me (ฉัน) และ Who has access: Anyone (ทุกคน)
  5. กด Deploy แล้วคัดลอก Web app URL มาวางในช่องด้านบนนี้
